% ABSTRACT
% ============================================================================
\begin{abstract}
Signature scanners and opaque machine-learning classifiers struggle against emerging social-engineering lures (such as ClickFix clipboard-paste execution), zero-day server remote code execution (RCE), prompt-injected AI coding agents, and stealth userland/kernel rootkits---while frequently exfiltrating sensitive command lines, URLs, and credentials into centralized telemetry lakes. We present \textbf{Refmon} (\emph{Provenance Gate v2}, specification \texttt{v2.0}), a deterministic, platform-agnostic reference monitor that detects, contains, and explains attacks by judging \emph{post-exploitation behavioral consequences} rather than exploit payloads. Refmon evaluates every causal ``story'' of system events along three orthogonal axes---\textbf{Origin} (untrusted external provenance), \textbf{Contract} (deviations from cryptographically signed per-role behavioral allowances), and \textbf{Effect} (high-risk capabilities)---combined via a monotone question-grouped log-likelihood ratio (LLR) calculus in natural log-odds units (\emph{nats}) against Bayes-optimal cost thresholds ($\tau_{\text{hold}}, \tau_{\text{block}}$) and a mandatory \emph{Contract Gate}. Raw payloads never leave an in-memory \texttt{Observe} boundary, where content is irreversibly converted into per-device HMAC-SHA256 digests after extracting scalar obfuscation features and confirming Bloom-filtered threat indicators. We further integrate a six-engine read-only cross-view rootkit sensor using multi-pass discrepancy intersection and an authenticated, unprivileged user-space command barrier that predicts a command's behaviour from its de-obfuscated text before it runs, together with a live audit dashboard suitable for shared university HPC clusters. Every structural change is evaluated under a pre-registration protocol: only on mutation variants generated from a random seed recorded \emph{before} the change was written (nine seeds from \texttt{v1.0} to \texttt{v2.0}). Across 46 golden scenarios spanning 17 attack families, 886 fresh mutation variants, a 16-scenario live attack/control suite, and over 1,860 automated unit and property tests, Refmon \texttt{v2.0} achieves 100\% golden accuracy, contains 98.4\% of mutated attack variants (Wilson 95\% CI $[97.1, 99.1]$) at a 0.0\% neutral false-block rate ($[0.0, 2.4]$; $1.3\%$ for \texttt{v1.7} on the same variants), and passes adversarial privacy audits with zero raw content leaks and zero fingerprint reversals.
\end{abstract}

\noindent\textbf{Keywords:} Reference Monitor, Dynamic Provenance Tracking, Role Contracts, Bayesian Log-Likelihood Calculus, Differential Privacy, Cross-View Rootkit Detection, ClickFix Defense, HPC Cluster Security.

\section{Introduction}
\label{sec:intro}

Modern computing environments---ranging from user workstations and web application servers to shared multi-tenant university High-Performance Computing (HPC) clusters---face attack vectors that bypass traditional perimeter and signature defenses. Three trends exemplify this shift:
\begin{enumerate}[leftmargin=1.4em,itemsep=1.5pt,topsep=2pt]
  \item \textbf{Human-in-the-loop social engineering (ClickFix / TerminalFix / FileFix):} Rather than delivering a binary executable that anti-virus engines can quarantine, adversaries display fraudulent browser verification prompts or documentation snippets instructing the user to copy and paste a shell pipeline (e.g., \texttt{curl ... | sh} or base64-encoded PowerShell) directly into an interactive terminal~\cite{mitre2024attack}. Even when the user is deceived, a runtime barrier should intercept the pasted execution before harm occurs.
  \item \textbf{Zero-day server RCE and AI agent hijacking:} Memory-corruption or deserialization flaws in web workers and Node.js runtimes (\texttt{PHP2Shell}, \texttt{Node2Shell}), as well as indirect prompt injections against autonomous AI coding agents~\cite{greshake2023not}, coerce trusted processes into spawning shells, dropping executable web shells, or reading application secrets.
  \item \textbf{Stealth rootkits and defense tampering:} Userland preload rootkits (\texttt{LD\_PRELOAD}, \texttt{/etc/ld.so.preload}), fileless \texttt{memfd\_create} binaries, and loadable kernel module (LKM) rootkits hide processes, sockets, and modules from standard administrative utilities while attempting to blind monitoring daemons~\cite{wang2005strider}.
\end{enumerate}

Existing Endpoint Detection and Response (EDR) tools suffer from two structural weaknesses when deployed in academic or privacy-regulated environments. First, signature-driven rules fail on unseen zero-day exploits, while black-box neural anomaly detectors produce unexplainable alerts and remain vulnerable to baseline poisoning. Second, commercial EDR agents routinely record raw command-line arguments, HTTP bodies, file paths, and environment variables on disk or transmit them to cloud backends---violating European data-protection norms and exposing research secrets or credentials stored in shell histories.

\paragraph{Core Insight.} Regardless of how an unknown vulnerability is exploited or how a user is socially engineered, the attacker must subsequently \emph{act} to achieve objectives: spawn unexpected programs, write executable scripts into web roots, connect to unlisted external hosts, read credential stores, escalate privileges, encrypt files en masse, or tamper with security tooling. Those post-compromise actions violate the \emph{role contract} of the acting process.

\paragraph{Contributions.} This paper presents the design, mathematical foundations, implementation, and evaluation of \textbf{Refmon} (\emph{Provenance Gate v2}, specification \texttt{v2.0}):
\begin{itemize}[leftmargin=1.3em,itemsep=1.5pt,topsep=2pt]
  \item \textbf{Privacy-First Six-Stage Reference Monitor (\S\ref{sec:method}):} A platform-independent pipeline (\texttt{Observe} $\to$ \texttt{Tag} $\to$ \texttt{Link} $\to$ \texttt{Judge} $\to$ \texttt{Gate} $\to$ \texttt{Report}) enforcing an irreversible RAM-only privacy boundary via keyed HMAC-SHA256 digests, local Bloom-confirmed threat lists, $\varepsilon$-differential privacy, $k$-anonymity, and four-eyes pseudonym re-identification.
  \item \textbf{Monotone Bayesian Log-Odds Calculus \& Contract Gate (\S\ref{sec:judge}--\ref{sec:rates}):} A deterministic, training-free mathematical engine combining exponential provenance decay, Noisy-OR label fusion, Laplace-smoothed role surprisal, Good-Turing baseline maturity, dual-window Poisson/CUSUM rate tests, and Bayes minimal-risk thresholds ($\tau_{\text{hold}}, \tau_{\text{block}}$), including a proven monotonicity fix (\texttt{v1.3}) resolving a subtle jump discontinuity under fading labels, and trusted provenance modelled as lineage with a bounded lifetime (\texttt{v2.0}).
  \item \textbf{Six-Engine Cross-View Rootkit Sensor \& Unprivileged Cluster Barrier (\S\ref{sec:rootkit}, \S\ref{sec:impl}):} Read-only user-space rootkit detection comparing high-level OS enumerations against low-level kernel/memory invariants across multiple passes, paired with an Ed25519-signed policy barrier, a token-authenticated local API, a de-obfuscating command-intent analyser, automatic file quarantine, and a clean light-theme telemetry interface operable without \texttt{root} privileges on shared Linux nodes.
  \item \textbf{Rigorous Reproducible Evaluation \& Complete Proofs (\S\ref{sec:eval}, Appendices~\ref{app:decay}--\ref{app:rootkit}):} Pre-registered variant-seed evaluation of every version from \texttt{v1.0} to \texttt{v2.0} across 46 golden scenarios, nine pre-registered variant seeds (886 mutated streams for \texttt{v2.0}), 16 live attack/benign scenarios, held-out command-evasion probes, and formal proofs of every mathematical property.
\end{itemize}

\section{Background and Related Work}
\label{sec:related}

\subsection{Reference Monitors and Information-Flow Provenance}
Anderson's classical Reference Monitor concept~\cite{anderson1972computer} stipulates three requirements for an access mediation mechanism: it must be \emph{tamperproof}, \emph{always invoked}, and \emph{small enough to be subject to complete analysis and tests}. Denning~\cite{denning1976lattice} formalized lattice-based information-flow control, demonstrating how security labels propagate from untrusted inputs to derived data and processes. Dynamic taint analysis systems such as TaintCheck~\cite{newsome2005dynamic} track byte-level taint at high instrumentation cost ($5\times$--$30\times$ slowdown), whereas whole-system provenance monitors---including CamFlow~\cite{pasquier2017practical}, Sleuth~\cite{hossain2017sleuth}, Holmes~\cite{milajerdi2019holmes}, and Unicorn~\cite{han2020unicorn}---track causal graphs at the OS process, file, and socket granularity.

Unlike graph-embedding approaches such as Unicorn~\cite{han2020unicorn} that hash multi-hop neighborhoods into high-dimensional sketches classified by unsupervised clustering (making individual false positives opaque to operators), Refmon aligns with Holmes~\cite{milajerdi2019holmes} in correlating causal stories against high-level tactics, while introducing explicit \emph{role contracts}, continuous half-life decay with persistent contract evidence, and exact cost-derived log-odds thresholds.

\subsection{Mandatory Access Control and Process Contracts}
Linux security frameworks such as SELinux~\cite{smalley2001implementing}, AppArmor~\cite{bauer2006paranoid}, and Seccomp-BPF~\cite{corbet2012seccomp} enforce static per-binary mandatory access control (MAC) profiles. While effective for rigidly confined daemons, static MAC profiles cannot distinguish \emph{provenance context}: an interactive shell (\texttt{bash}) must be allowed to execute \texttt{curl} and \texttt{sh} during normal developer workflows, yet the exact same shell executing command text pasted from an untrusted webpage (ClickFix) represents a severe breach. Refmon bridges MAC contracts and dynamic provenance via \emph{provenance-conditioned contracts} (e.g., \texttt{external\_content\_exec: deny} and Design Decision D23, where role-permitted high-volume effects remain benign unless tainted by an external origin label).

\subsection{Sequential Hypothesis Testing and Bayesian Fusion}
Wald's Sequential Probability Ratio Test (SPRT)~\cite{wald1945sequential} and Page's Cumulative Sum (CUSUM) control chart~\cite{page1954continuous}, proved minimax-optimal by Lorden~\cite{lorden1971procedures}, form the bedrock of statistical change-point detection in network intrusion detection~\cite{jung2004fast}. Naive Bayes alert correlators sum log-likelihood ratios across all firing rules, which severely overcounts correlated indicators within the same behavioral dimension (e.g., three overlapping network-fetch heuristics firing on a single socket). Pearl's Noisy-OR model~\cite{pearl1988probabilistic} handles independent causal pathways for label combination, while Refmon's \emph{max-within-question, sum-across-questions} operator (\S\ref{sec:judge}) bounds within-axis correlation while preserving additive Bayesian evidence across orthogonal questions.

\subsection{Cross-View Rootkit Detection}
Host rootkit scanners such as \texttt{chkrootkit} and \texttt{rkhunter} rely heavily on static file-path signatures and known bad hashes, missing novel LKM hooks or memory-only implants. Cross-view diffing, pioneered by Strider GhostBuster~\cite{wang2005strider} and formalized in virtual-machine introspection~\cite{garfinkel2003virtual}, compares a high-level API listing (susceptible to syscall or \texttt{readdir} hooking) against a lower-level structural view (e.g., kernel object trees in \texttt{/sys/module} or direct \texttt{kill(pid, 0)} / \texttt{/proc/[pid]/status} probes). Single-pass user-space scanners such as \texttt{unhide} suffer from transient race conditions when short-lived processes exit mid-scan; Refmon resolves this via $m$-pass discrepancy intersection integrated directly into its log-odds engine.

\subsection{Privacy-Preserving Security Telemetry}
Storing cleartext audit logs creates a high-value target for attackers and insiders. Cryptographic keyed hashing via HMAC~\cite{bellare1996keying} provides collision-resistant and preimage-resistant correlation tokens when keyed with a device-local secret, while Bloom filters~\cite{bloom1970space} enable compact threat-indicator distribution. For cross-device fleet aggregation, $\varepsilon$-differential privacy~\cite{dwork2006calibrating} and $k$-anonymity~\cite{sweeney2002kanonymity} bound membership disclosure. Refmon combines all four mechanisms with cryptographic policy signing (Ed25519~\cite{bernstein2012high}) and four-eyes dual-approver pseudonym escrow.

\subsection{System Architecture and Core Principles}
\label{sec:arch}

Figures~\ref{fig:pipeline_img} and~\ref{fig:tikz_dataflow} depict the six-stage architecture of Refmon. Platform-specific sensors emit in-memory \texttt{RawEvent} tuples $(e_{\text{id}}, t, d, \tau, a, o_{\text{raw}}, \alpha_{\text{raw}})$ across 13 canonical event types:
\[
\begin{aligned}
\mathcal{T} = \{&\texttt{content\_in}, \texttt{request\_in}, \texttt{request\_end},\\
&\texttt{exec}, \texttt{net\_connect}, \texttt{file\_write}, \texttt{persist},\\
&\texttt{asset\_access}, \texttt{priv\_change}, \texttt{security\_tamper},\\
&\texttt{user\_input}, \texttt{admin\_input}, \texttt{response\_out}\}.
\end{aligned}
\]
Each actor $a = (\text{id}, \text{parent}, r, \text{interactive}, u)$ carries a workload role $r \in \mathcal{R}$ (16 built-in roles such as \texttt{interactive\_shell}, \texttt{web\_worker}, \texttt{node\_app\_server}, \texttt{package\_installer}, \texttt{office}, \texttt{launcher}, \texttt{agent}, \texttt{browser}, \texttt{mail}, plus policy-extensible roles \texttt{backup\_job}, \texttt{vuln\_scanner}, \texttt{patch\_tool}).

Two foundational invariants govern the entire pipeline:
\begin{invariant}[Zero Raw Persistence]
\label{inv:raw}
No raw payload $c = o_{\text{raw}}.\text{content}$ or free-text attribute (\texttt{domain}, \texttt{host}, \texttt{ip}, \texttt{url\_path}, \texttt{program}, \texttt{signer}) ever crosses the output boundary of \texttt{Observe}. Post-\texttt{Observe} \texttt{Event} records validate against a strict 21-key scalar/identifier allowlist $\mathcal{K}_{\text{allow}}$.
\end{invariant}
\begin{invariant}[Missing Information Neutrality]
\label{inv:missing}
Whenever a sensor lacks a capability (e.g., code-signature verification returns \texttt{signed = "unknown"} or a learned role baseline is not yet statistically mature), the dependent signal is omitted ($s_j = 0$) rather than treated as suspicious, and the capability gap is reported out-of-band via the \texttt{Heartbeat} monitor.
\end{invariant}

\subsection{Stage 1 (\texttt{Observe}): Cryptographic Privacy Boundary and Obfuscation Features}
\label{sec:observe}

Given raw content string $c \in \Sigma^*$ and a 256-bit device-local secret key $K_{\text{dev}}$, \texttt{Observe} first whitespace-normalizes $\tilde{c} = \text{norm}(c)$ and computes its irreversible fingerprint:
\begin{equation}
  f(c) = \texttt{"hmac:"} \,\|\, \operatorname{Hex}\!\Big(\operatorname{HMAC-SHA256}\big(K_{\text{dev}},\, \tilde{c}\big)\Big).
  \label{eq:hmac}
\end{equation}

Before discarding $c$ from RAM, if $\tau \in \{\texttt{exec},\allowbreak \texttt{content\_in},\allowbreak \texttt{user\_input},\allowbreak \texttt{admin\_input}\}$, \texttt{Observe} extracts three scalar obfuscation metrics over the character histogram $\{n_x\}_{x \in \Sigma}$ of $c$ ($N_c = |c| > 0$, $p_x = n_x / N_c$):
\begin{align}
  H(c) &= -\sum_{x \in \Sigma,\, p_x > 0} p_x \log_2 p_x \quad\text{(bits/char)}, \label{eq:entropy}\\
  \rho_{\text{enc}}(c) &= \frac{1}{N_c}\sum_{i=1}^{N_c} \mathbf{1}\!\left[c_i \in \Sigma_{\text{b64/hex}}\right], \label{eq:encratio}\\
  r_{\text{ws}}(c) &= \max\big\{\ell \in \mathbb{N} : \exists\, i,\; c_{i..i+\ell-1} \in \{\text{' '}, \text{'\textbackslash t'}\}^\ell\big\}. \label{eq:wsrun}
\end{align}
The \texttt{effect\_hide} signal fires whenever $H(c) > H_{\max}$ ($5.2$~bits), $r_{\text{ws}}(c) > r_{\max}$, or explicit \texttt{hidden\_window} / \texttt{encoded\_payload} flags hold, catching base64-encoded lures and ClickFix whitespace-padding attacks (where malicious commands are pushed off-screen via hundreds of spaces) without retaining a single character of $c$.

\paragraph{Two-Stage Bloom Threat Confirmation.} Threat indicators $\mathcal{D}_{\text{bad}}$ are stored as list-keyed HMAC digests $d_i = \operatorname{HMAC-SHA256}(K_{\text{list}}, \tilde{v}_i)$ inside a bit-array Bloom filter $\mathcal{B}$ of size $m$ bits and $k_h$ double-hashed indices:
\begin{equation}
  m = \left\lceil -\frac{n \ln p_{\text{fp}}}{(\ln 2)^2} \right\rceil, \qquad
  k_h = \max\!\left(1,\, \operatorname{round}\!\left(\frac{m}{n}\ln 2\right)\right),
  \label{eq:bloom}
\end{equation}
sized for $p_{\text{fp}} \le 10^{-3}$. Any Bloom hit $\mathcal{B}.\text{might\_contain}(d) = 1$ is treated strictly as a fast filter hint and verified against the exact digest set $\mathcal{D}_{\text{exact}}$ inside \texttt{Observe}, guaranteeing an operational threat-list false-positive rate of \emph{strictly zero} (proved in Appendix~\ref{app:privacy}).

\subsection{Stage 2 (\texttt{Tag}): Provenance DAG, Decay, and Noisy-OR Fusion}
\label{sec:tag}

Untrusted external ingress ($\tau \in \{\texttt{content\_in},\allowbreak \texttt{request\_in}\}$ with \texttt{source\_class} in \{\texttt{web}, \texttt{mail}, \texttt{removable}, \texttt{download}, \texttt{inbound\_request}, \texttt{outbound\_response}, \texttt{package}, \texttt{agent\_input}\} and not matching \texttt{trusted\_sources}) mints a provenance label $\ell = (\text{id}, t_0, s_0=1, \text{persistent}, \mathcal{E}_{\text{contract}})$.

\paragraph{Exponential Half-Life Decay.} At event timestamp $t \ge t_0$ ($\Delta t = t - t_0$), a non-persistent label with no recorded contract violation decays with policy half-life $T_{1/2}$ ($30$~min):
\begin{equation}
  s_\ell(t) =
  \begin{cases}
    s_0, & \text{if } \ell.\text{pers.} \lor \mathcal{E}_{\text{contract}}(\ell) \neq \varnothing,\\[3pt]
    s_0 \, 2^{-\Delta t / T_{1/2}}, & \text{otherwise.}
  \end{cases}
  \label{eq:decay}
\end{equation}
Freezing decay once $\mathcal{E}_{\text{contract}}(\ell) \neq \varnothing$ (\texttt{v1.1}, decision A49) prevents an adversary from executing an initial contract breach, sleeping past $T_{1/2}$, and resuming post-exploitation unlabeled.

\paragraph{Edge Attenuation and Noisy-OR Combination.} Across a causal edge $e$ with attenuation $a_e \in (0, 1]$, child strength is $s_{\text{child}} = a_e \cdot s_{\text{parent}}$. When an actor or object carries multiple active labels $\{\ell_1, \dots, \ell_m\}$ with strengths $s_1, \dots, s_m \in [0, 1]$, their combined external-origin strength is fused via Pearl's Noisy-OR operator:
\begin{equation}
  s_{\text{comb}}(t) = 1 - \prod_{i=1}^{m} \big(1 - s_{\ell_i}(t)\big).
  \label{eq:noisyor}
\end{equation}
When a labeled process writes an executable to a configured \texttt{web\_root} or creates a startup entry (\texttt{persist}), the target object receives $\text{persistent} = \texttt{true}$ along with the originating story's contract violations $\mathcal{E}_{\text{contract}}$, ensuring delayed execution days later (Scenario \texttt{S06}) inherits full contract evidence.

\paragraph{Order-Independent Label Hand-Over (\texttt{v1.7}, A64).} External content whose fingerprint already carries labels hands \emph{every} live label to the ingesting process (as an \texttt{exec} of labeled command text always did), not only the strongest one. Which label is strongest depends on the decay speed, so the earlier rule let the half-life change which stories events linked into; a randomised property test found a counterexample in which a faster-fading label produced a stronger story. Several labels combine by Eq.~\eqref{eq:noisyor}, so nothing is counted twice.

\paragraph{Trusted Provenance as Lineage (\texttt{v2.0}, A65).} Trusted root sources (e.g.\ a university software portal) create no label (rule~6). Until \texttt{v1.7}, trust was therefore a property of a single story, whereas external provenance was a property of the process lineage: a later step of a signed installation further away than the quiet window $W_q$ opened a new story without trust and could be blocked, although an external label in the same position would still have counted (finding F10). In \texttt{v2.0}, a non-channel process $p$ that ingests trusted content at time $t_p$ carries a \emph{trust mark}, inherited by its children, which is live at time $t$ iff
\begin{equation}
  \begin{aligned}
  \operatorname{trust}_p(t) = {}&\mathbf{1}\!\Big[\,2^{-(t - t_p)/T_{1/2}} \ge s_{\text{floor}}\Big]\\
  &\cdot \mathbf{1}\!\Big[\nexists\, \ell \in \operatorname{ever}(p) : s_\ell(t) \ge s_{\text{floor}}\Big],
  \end{aligned}
  \label{eq:trust}
\end{equation}
where $s_{\text{floor}} = 0.02$ is the label alive floor and $\operatorname{ever}(p)$ is every label the lineage of $p$ has carried. The mark thus lives exactly as long as a non-persistent label created at $t_p$ would ($T_{1/2}\log_2(1/s_{\text{floor}}) \approx 2.8$~h), is cancelled by any live external label in the lineage (even one faded below $\theta_{\text{ori}}$), is not acquired by a channel role that ingests trusted content, and never passes to files or persistence items (Proposition~\ref{prop:trust}, Appendix~\ref{app:trust}).

\subsection{Stage 3 (\texttt{Link}): Causal Story Equivalence}
\label{sec:link}

\texttt{Link} maintains a dynamic partition of observed events into causal stories $\{S_1, S_2, \dots\}$. Process-keyed actors merge along parent-child spawn trees ($\text{actor.parent}$) and shared labeled object fingerprints within the policy quiet window $W_q$ ($10$~min), whereas channel roles (\texttt{browser}, \texttt{mail}) are excluded as merge keys (\texttt{non\_process\_keyed\_roles}) so two unrelated downloads opened in the same browser never contaminate each other's stories.

For each story $S$, let $s_{\text{ori}}(S) = \max_{\ell \in \mathcal{L}(S)} s_\ell(t_{\text{last}})$ denote the strongest active provenance label. \texttt{Judge} evaluates three questions $\mathcal{Q} = \{\text{origin}, \text{contract}, \text{effect}\}$:
\begin{itemize}[leftmargin=1.3em,itemsep=1pt,topsep=2pt]
  \item $Q_{\text{origin}}$ fails iff $s_{\text{ori}}(S) \ge \theta_{\text{ori}}$ ($0.5$), yielding signal \texttt{origin\_external} with strength $s_{\text{ori}}(S) \in [\theta_{\text{ori}}, 1]$.
  \item $Q_{\text{contract}}$ fails iff $\mathcal{S}_{\text{contract}}(S) \neq \varnothing$ (role violation, universal violation, unsigned external launch, or mature role surprisal), each with unit strength $s_j = 1$.
  \item $Q_{\text{effect}}$ fails iff $\mathcal{S}_{\text{effect}}(S) \neq \varnothing$ after filtering role-allowed effects when $\neg Q_{\text{origin}}$ (Design Decision D23), each with unit strength $s_j = 1$.
\end{itemize}
A connection to a destination class marked \texttt{trusted} raises no \texttt{effect\_fetch} for an unlabeled process, but since \texttt{v1.5} (A60) only when no live external label exists anywhere in the process's lineage: a downloaded script whose label has faded below $\theta_{\text{ori}}$ is still not excused by a popular trusted host.

\paragraph{Max-Sum Log-Likelihood Ratio Calculus.} Each signal $j$ carries weight
\begin{equation}
  w_j = \ln \frac{\mathbb{P}(j \mid \text{attack})}{\mathbb{P}(j \mid \text{benign})} \quad (\text{in nats}),
  \label{eq:llr_weight}
\end{equation}
either fixed from expert prior rates in the signed policy (Table~\ref{tab:weights}) or re-estimated from labeled replay corpora with Laplace smoothing:
\begin{equation}
  \hat{w}_j = \ln \frac{(a_j + 1)/(|\mathcal{A}| + 2)}{(b_j + 1)/(|\mathcal{B}| + 2)}.
  \label{eq:reestimate}
\end{equation}
Given prior attack probability $\pi \in (0, 1)$ ($\pi = 10^{-3} \implies L_0 = \ln\frac{\pi}{1-\pi} \approx -6.9068$~nats), the posterior log-odds of story $S$ is:
\begin{equation}
  L(S) = \ln\frac{\pi}{1 - \pi} + \sum_{q \in \{\text{origin},\,\text{contract},\,\text{effect}\}} \;\max_{j \in \mathcal{S}_q(S)} \big(w_j \cdot s_j\big),
  \label{eq:logodds}
\end{equation}
with empty maxima defined as $0$, and posterior probability $\mathbb{P}(\text{attack} \mid S) = \sigma(L(S)) = (1 + e^{-L(S)})^{-1}$. Crucially, in \texttt{v1.3} (Decision A55), only $Q_{\text{origin}}$ scales by $s_{\text{ori}}(S)$ while Contract and Effect signals take $s_j = 1$, guaranteeing that $L(S)$ is monotonically non-decreasing in label strength (Theorem~\ref{thm:monotone}, Appendix~\ref{app:monotone}).

\paragraph{Cost-Based Decision Rule, Overrides, and Contract Gate.} Let $C_{\text{miss}}$ ($1000$), $C_{\text{fb}}$ ($20$), and $C_{\text{hold}}$ ($5$) denote the operational costs of a missed attack, a false block, and a human hold, and let $h \in (0, 1]$ ($0.7$) denote the probability that a hold stops a real attack. Bayes minimal-risk decision theory (proved in Appendix~\ref{app:bayes}) yields exact log-odds thresholds:
\begin{equation}
  \tau_{\text{block}} = \ln\frac{C_{\text{fb}}}{C_{\text{miss}}} \approx -3.91,\quad
  \tau_{\text{hold}} = \ln\frac{C_{\text{hold}}}{h C_{\text{miss}}} \approx -4.94.
  \label{eq:thresholds}
\end{equation}
Preceding the calculus, four deterministic overrides $\mathcal{O}$ apply in strict priority order: (1)~\texttt{OVR-}\allowbreak\texttt{SELF-TAMPER} $\mapsto \texttt{BLOCK}$, (2)~\texttt{OVR-CANARY} $\mapsto \texttt{BLOCK}$, (3)~\texttt{OVR-}\allowbreak\texttt{PROTECTED-ASSET} (labeled actor reading protected asset) $\mapsto \texttt{BLOCK}$, and (4)~\texttt{OVR-}\allowbreak\texttt{TRUSTED-ROOT} (an unlabeled story with an event that ingests trusted-root content or is performed by a process whose trust mark is live, Eq.~\eqref{eq:trust}) $\mapsto \texttt{ALLOW}$. When $\mathcal{O} = \varnothing$, the final decision $D(S)$ enforces the \textbf{Contract Gate} (Figure~\ref{fig:tikz_thresholds}):
\begin{equation}
  D(S) =
  \begin{cases}
    \texttt{BLOCK}, & \text{if } L(S) \ge \tau_{\text{block}} \;\land\; Q_{\text{contract}}(S),\\
    \texttt{HOLD},  & \text{if } \big(L(S) \ge \tau_{\text{block}} \;\land\; \neg Q_{\text{contract}}(S)\big)\\
                    & \quad\;\lor\; \big(\tau_{\text{hold}} \le L(S) < \tau_{\text{block}}\big),\\
    \texttt{ALLOW}, & \text{if } L(S) < \tau_{\text{hold}}.
  \end{cases}
  \label{eq:decide}
\end{equation}

\subsection{Contract Surprisal and Good-Turing Maturity}
\label{sec:rarity}

During contract learning or baseline counting for role $r$, let $n_{r,e}$ denote the observed count of event behavior kind $e$, $N_r = \sum_{e=1}^{K_r} n_{r,e}$ the total observations over $K_r$ distinct seen kinds, and $n_{r,1} = |\{e : n_{r,e} = 1\}|$ the number of singleton kinds. With Laplace smoothing ($\alpha = 1$) reserving one pseudocount bin for all unseen behaviors ($K_r + 1$ bins total), the smoothed probability and Shannon surprisal are:
\begin{equation}
  \hat{p}(e \mid r) = \frac{n_{r,e} + \alpha}{N_r + \alpha(K_r + 1)}, \quad
  I(e \mid r) = -\log_2 \hat{p}(e \mid r).
  \label{eq:surprisal}
\end{equation}
To uphold Invariant~\ref{inv:missing}, neither learned contracts nor \texttt{contract\_surprisal} ($I(e \mid r) \ge I_{\max} = 12$~bits) activate until the Good-Turing unseen probability mass falls below $\tau_{\text{mat}} = 0.01$:
\begin{equation}
  \hat{p}_{\text{unseen}}(r) = \frac{n_{r,1}}{N_r} < \tau_{\text{mat}}.
  \label{eq:goodturing}
\end{equation}

\subsection{Dual-Window Statistical Rate and Drift Detectors}
\label{sec:rates}

Refmon monitors burst rates over both a short window ($60$~s) and a long window ($1$~h) so attackers cannot evade burst thresholds simply by spacing operations minutes apart:
\begin{enumerate}[leftmargin=1.4em,itemsep=1.5pt,topsep=2pt]
  \item \textbf{Poisson Upper-Tail Burst Test (\texttt{mass\_change}, \texttt{lateral}, repeated \texttt{response\_anomaly}):} Given EMA baseline rate $\hat{\lambda}$ and $k$ distinct items in the active window, an alert fires iff
  \begin{equation}
    \mathbb{P}(X \ge k \mid \operatorname{Pois}(\hat{\lambda})) = \sum_{i=k}^{\infty} \frac{e^{-\hat{\lambda}}\hat{\lambda}^i}{i!} < 10^{-6}.
    \label{eq:poisson}
  \end{equation}
  \item \textbf{Standardized One-Sided CUSUM (\texttt{exfil} volume):} For role outbound byte volume $x_t$ with role mean $\mu_r$, standard deviation $\sigma_r$, standardized score $z_t = (x_t - \mu_r)/\sigma_r$, slack $k_c = 0.5$, and threshold $h_c = 5.0$:
  \begin{equation}
    S_t = \max\big(0,\, S_{t-1} + z_t - k_c\big), \qquad \text{alert iff } S_t > h_c.
    \label{eq:cusum}
  \end{equation}
\end{enumerate}
All EMA baselines $\hat{\lambda}_t = (1-\beta)\hat{\lambda}_{t-1} + \beta y_t$ freeze ($\text{frozen}=\texttt{true}$) whenever an incident on that process tree is open, preventing adversarial baseline poisoning. Since \texttt{v1.5} (A61) an incident ends once its process tree has been silent for the long window ($1$~h); before, an incident closed only when its tree later produced an allowed story, which a contained tree never does, so a single block froze every baseline indefinitely. A long-running daemon additionally forgets stories, idle processes, dead labels and rate state older than a retention horizon $r \ge \max(W_q, 1\,\text{h})$ (A62), never a story with a pending hold and never a process whose label or trust mark is still live, so its memory stays bounded without changing any decision on a retained story.

\subsection{Six-Engine Cross-View Rootkit Calculus}
\label{sec:rootkit}

To detect userland and kernel stealth implants without requiring root privileges, Refmon executes $m \ge 2$ passes separated by $\Delta \tau$ across six read-only engines: (E1)~dynamic linker hijacking (\texttt{/etc/ld.so.preload}, \texttt{LD\_PRELOAD}, \texttt{LD\_AUDIT}, ephemeral \texttt{LD\_LIBRARY\_PATH}, deleted or ephemeral shared libraries), (E2)~fileless execution and memory injection (\texttt{memfd:}, deleted \texttt{/proc/[pid]/exe} links, execution from \texttt{/dev/shm} or \texttt{/tmp}, non-zero \texttt{TracerPid}, anonymous \texttt{rwxp} segments), (E3)~LKM cross-view (\texttt{/sys/module} $\setminus$ \texttt{/proc/modules}) with kernel taint decoding (\texttt{/proc/sys/kernel/taint}: forced load or unload is scored, while the proprietary, out-of-tree and unsigned-module bits of GPU/DKMS drivers are recorded as context only), (E4)~PID cross-view (\texttt{/proc} enumeration versus thread groups and own-UID ancestry, without sending signals), (E5)~socket cross-view and sniffer check (\texttt{TCP: inuse} of \texttt{/proc/net/sockstat} versus the lines of \texttt{/proc/net/tcp}, and \texttt{IFF\_PROMISC} interfaces), and (E6)~an optional bridge to installed \texttt{unhide}, \texttt{chkrootkit} or \texttt{rkhunter}, where a missing tool adds no evidence.

Persistent cross-view discrepancies are isolated by multi-pass set intersection:
\begin{equation}
  \Delta_{\text{pers}} = \bigcap_{r=1}^{m} \Big(\mathcal{V}_{\text{low}}^{(r)} \setminus \mathcal{V}_{\text{high}}^{(r)}\Big),
  \label{eq:crossview_intersect}
\end{equation}
suppressing transient process/module churn exponentially in $m$ (Appendix~\ref{app:rootkit}). Confirmed discrepancies map to bounded log-odds evidence:
\begin{equation}
  w_{\text{rk}}(d, m) = \min\!\Big(w_{\max},\; \ln\frac{p_{\text{tp}}}{p_{\text{race}}} + (m - 1)\ln\frac{1}{q_{\text{persist}}}\Big),
  \label{eq:rk_nats}
\end{equation}
The implementation treats passes as independent ($q_{\text{persist}} = p_{\text{race}} = 10^{-3}$, $p_{\text{tp}} = 0.99$, $w_{\max} = 8$~nats), so two passes already reach the cap; a cross-view finding counts with the larger of this weight and its base weight, and single-pass findings use fixed base weights (e.g.\ $2.2$~nats for anonymous \texttt{rwxp} memory, $5.2$ for \texttt{LD\_PRELOAD}). Findings are emitted as privacy-redacted \texttt{SECURITY\_TAMPER} or \texttt{EXEC} events directly into \texttt{Pipeline}.

\section{Experiments, Algorithms, and Implementation Tests}

\subsection{Reference Implementation and Signed Policy Governance}
\label{sec:impl}

Refmon is implemented in approximately 12,400 lines of strict, type-checked Python~3.12 (plus 10,200 lines of tests) (\texttt{pydantic} v2 frozen schemas, \texttt{cryptography} Ed25519 signatures, zero runtime machine-learning dependencies). Every threshold, weight, role contract, canary, and rate parameter resides in a canonical JSON-serialized, Ed25519-signed \texttt{policy.yaml}; startup and live reload reject any unsigned or tampered policy (\texttt{PolicyRejected}) and retain the last verified state. A periodic \texttt{SelfTest} scheduler clones the live pipeline via \texttt{pipeline.probe()} (preserving live disabled rules and weights while isolating outputs) to inject synthetic health stories and raise immediate alerts if any enabled protection fails to reach its expected decision.

\subsection{Core Pipeline and Scanner Algorithms}
\label{sec:algorithms}

Algorithms~\ref{alg:pipeline}, \ref{alg:judge}, and~\ref{alg:rootkit} specify the exact deterministic execution of the Refmon event loop, the monotone Bayesian \texttt{Judge}, and the multi-pass cross-view rootkit sensor. Listing~\ref{lst:barrier} shows the core unprivileged command-barrier enforcement loop from \texttt{src/refmon/live.py}.

\begin{algbox}{End-to-End Refmon Event Processing (\texttt{Pipeline.process})}{alg:pipeline}
  \item \textbf{Input:} Sensor event $e_{\text{raw}} \in \texttt{RawEvent} \cup \texttt{Event}$, verified policy $\Pi$, device HMAC key $K_{\text{dev}}$.
  \item \textbf{Output:} Emitted verdicts and containment actions $\mathcal{V} \subseteq \texttt{Verdict} \cup \texttt{Action}$.
  \item $e \leftarrow \textsc{Observe}(e_{\text{raw}}, \Pi, K_{\text{dev}})$ \hfill $\triangleright$ Compute $\text{HMAC}_{K_{\text{dev}}}$, $H(c)$, Bloom+Exact check; drop raw content
  \item $p_{\text{known}} \leftarrow (e.\text{actor.parent} \in \text{Tagger.procs})$
  \item $\text{tg} \leftarrow \textsc{Tag}(e, \Pi)$ \hfill $\triangleright$ Apply propagation rules 1--7, decay $2^{-\Delta t / T_{1/2}}$, Noisy-OR
  \item $(\mathcal{S}, \mathcal{F}) \leftarrow \textsc{ExtractSignals}(e, \text{tg}, \Pi, \text{Rates}, \text{Baseline})$
  \item $\text{rec} \leftarrow \textsc{Link}(\text{tg}, p_{\text{known}}, \mathcal{S}, \mathcal{F}, \Pi)$ \hfill $\triangleright$ Assign/merge story within quiet window $W_q$
  \item $J \leftarrow \textsc{Judge}(\text{rec}, \text{Tagger}, \Pi)$ \hfill $\triangleright$ Algorithm~\ref{alg:judge}
  \item $\text{Rates.mark\_incident}(\text{root}(e.\text{actor}),\, J.\text{decision} \neq \texttt{ALLOW},\, e.\text{ts})$ \hfill $\triangleright$ Freeze baselines; end incidents silent for 1~h
  \item \textbf{if} $\{s \in J.\text{signals} : s.\text{question}=\text{contract} \land \neg s.\text{carried}\} \neq \varnothing$ \textbf{then}
  \item \hspace{1.0em} Freeze decay and attach contract evidence to active labels $\ell \in \text{rec.label\_ids}$
  \item $\mathcal{V} \leftarrow \textsc{EmitVerdictIfChanged}(\text{rec}, J)$
  \item \textbf{if} $\text{Gate} \neq \texttt{None}$ \textbf{then} $\mathcal{V} \leftarrow \text{Gate.tick}(e.\text{ts}) \,\|\, \mathcal{V} \,\|\, \text{Gate.handle}(\text{rec}, J, e.\text{ts})$
  \item \textbf{return} $\mathcal{V}$
\end{algbox}

\begin{algbox}{Monotone Question-Grouped Bayesian Judge (\texttt{v2.0})}{alg:judge}
  \item \textbf{Input:} Story record $\text{rec}$, provenance tagger $\mathcal{T}$, signed policy $\Pi$.
  \item \textbf{Output:} Story judgement $J = (\text{decision}, L, \text{failed}, \text{override}, \text{gated})$.
  \item $s_{\text{ori}} \leftarrow \max_{\ell \in \text{rec.label\_ids}} \mathcal{T}.\text{strength}(\ell, \text{rec.last\_ts})$; \quad $\text{labeled} \leftarrow (s_{\text{ori}} \ge \Pi.\theta_{\text{ori}}) \land \Pi.\text{enabled}(\texttt{R-ORI})$
  \item Filter $\mathcal{S} \leftarrow \{s \in \text{rec.signals} : (\neg s.\text{allowed} \lor \text{labeled}) \land \Pi.\text{rule\_enabled}(s) \land s \notin \Pi.\text{exceptions}\}$
  \item Append persistent carried contract signals from $\{\ell \in \text{rec.label\_ids} : s_\ell \ge \Pi.\theta_{\text{ori}}\}$
  \item Check priority overrides $\mathcal{O}$: \texttt{self\_tamper} $\succ$ \texttt{canary} $\succ$ \texttt{protected\_asset} $\mapsto \texttt{BLOCK}$; unlabeled \texttt{trusted} (source event or live trust mark) $\mapsto \texttt{ALLOW}$
  \item \textbf{if} $\mathcal{O} \neq \texttt{None}$ \textbf{then return} forced override decision with audit trace
  \item $\mathcal{E} \leftarrow \{(s.\text{question}, s.\text{name}, 1.0) : s \in \mathcal{S}\}$ \hfill $\triangleright$ \texttt{v1.3}: unit strength for Contract \& Effect
  \item \textbf{if} $\text{labeled}$ \textbf{then} $\mathcal{E} \leftarrow \mathcal{E} \cup \{(\text{origin}, \texttt{origin\_external}, s_{\text{ori}})\}$
  \item $L \leftarrow \ln\frac{\Pi.\pi}{1 - \Pi.\pi} + \sum_{q \in \{\text{ori},\text{con},\text{eff}\}} \max_{(q, j, s_j) \in \mathcal{E}} (\Pi.w_j \cdot s_j)$
  \item $\tau_b \leftarrow \ln(\Pi.C_{\text{fb}} / \Pi.C_{\text{miss}})$; \quad $\tau_h \leftarrow \ln(\Pi.C_{\text{hold}} / (\Pi.h \cdot \Pi.C_{\text{miss}}))$; \quad $C_{\text{fail}} \leftarrow \exists s \in \mathcal{S}: s.\text{question}=\text{contract}$
  \item \textbf{if} $L \ge \tau_b \land C_{\text{fail}}$ \textbf{then return} $(\texttt{BLOCK}, L, \text{gated}=\texttt{false})$
  \item \textbf{else if} $L \ge \tau_b \land \neg C_{\text{fail}}$ \textbf{then return} $(\texttt{HOLD}, L, \text{gated}=\texttt{true})$ \hfill $\triangleright$ Contract Gate
  \item \textbf{else if} $L \ge \tau_h$ \textbf{then return} $(\texttt{HOLD}, L, \text{gated}=\texttt{false})$
  \item \textbf{else return} $(\texttt{ALLOW}, L, \text{gated}=\texttt{false})$
\end{algbox}

\section{Discussion}
\label{sec:discussion}

\subsection{Why Consequence-Oriented Contracts Generalize to Unseen Zero-Days}
Exploit techniques evolve rapidly, yet post-compromise objectives remain tightly constrained by operating-system semantics. Whether a web worker is compromised through a classic PHP file inclusion, a novel HTTP/3 heap overflow, or an unsafe Node.js deserialization gadget (\texttt{S13}, \texttt{S25}, \texttt{S26b--c}), spawning an interactive shell or writing an executable script into a web root violates the invariant contract of that worker role (\texttt{may\_exec: []}). Simultaneously, evaluating Origin and Effect alongside Contract prevents rigid MAC brittleness: when a developer copies a benign diagnostic command (\texttt{echo} or \texttt{git status}, Scenario~\texttt{S11}) from documentation, Origin ($+0.8$~nats) and Contract ($+1.0$~nats) fire, reaching $L = -5.11$~nats---safely below $\tau_{\text{hold}} = -4.94$~nats and avoiding alert fatigue.

\subsection{Discovery and Resolution of the Non-Monotonicity Flaw (Finding F8)}
Pre-registered mutation testing revealed a subtle mathematical pathology in versions prior to \texttt{v1.3}. Earlier versions scaled Contract and Effect signals by $s_{\text{ori}}$ whenever $s_{\text{ori}} \ge \theta_{\text{ori}} = 0.5$, while reverting to unit strength ($1.0$) when $s_{\text{ori}} < 0.5$ so unlabeled local breaches could still be caught. Consequently, a provenance label decaying from $s_{\text{ori}} = 0.70$ to $0.49$ abruptly \emph{increased} a Contract signal's contribution from $0.70 w_j$ to $1.00 w_j$---violating evidence monotonicity. Decoupling Contract and Effect strengths ($s_j \equiv 1$) from Origin's continuous decay in \texttt{v1.3} restored global monotonicity (proved in Appendix~\ref{app:monotone}) and upgraded 19 faded-label attack variants from \texttt{HOLD} to \texttt{BLOCK} ($p = 3.8 \times 10^{-6}$) without increasing neutral false blocks.

\subsection{Trust as Lineage and the Last False Blocks (Finding F10)}
The false blocks that remained through \texttt{v1.7} came from an asymmetry, not from a weight: external provenance lived in the process lineage and survived the story quiet window, whereas trusted provenance lived in a single story and did not. A signed installer that wrote its startup entry more than ten minutes after downloading its package was therefore judged as if nothing trusted had happened. Carrying the trusted-root override across stories had been rejected earlier because it widens an \emph{absolute} allow that a compromised signed updater could use. \texttt{v2.0} resolves the tension by giving trust exactly the lifetime of a label and strictly fewer paths (not acquired by channel roles, no files or persistence items, cancelled by any live external label, outranked by every blocking override), so the allow is widened in time only as far as an external label reaches, and in no new direction (Proposition~\ref{prop:trust}).

\subsection{Why Refmon Does Not Learn Its Decisions}
Reinforcement learning is a poor fit for the decision itself. Real attacks are rare, so rewards are sparse and delayed; an agent that explores by killing or quarantining processes on a shared node causes the harm it should prevent; feedback channels (``false alarm'', ``confirmed'') can be poisoned by the attacker; and a learned policy cannot state the exact evidence behind a verdict, which every Refmon verdict does in nats. Learning has two safe places outside the decision path: re-estimating weights offline from labeled replay counts (Eq.~\eqref{eq:reestimate}), applied only after human approval, and an adversarial search over the replay lab that looks for event sequences the deterministic monitor allows (Section~\ref{sec:future}).

\subsection{Documented Architectural Boundaries and Residual Gaps}
Refmon explicitly documents four fundamental limits rather than masking them behind overfitted weights:
\begin{enumerate}[leftmargin=1.4em,itemsep=1.5pt,topsep=2pt]
  \item \textbf{Unobserved Out-of-Band Channels (\texttt{S05}):} If a user manually types a malicious command viewed on a separate phone screen or video call, no digital \texttt{content\_in} event occurs on the host. With $Q_{\text{origin}}$ absent, \texttt{effect\_fetch} ($+2.5$~nats) raises $L$ to $-4.41 \ge \tau_{\text{hold}}$, pausing the process for human confirmation (\texttt{HOLD}) rather than silently allowing or blindly blocking.
  \item \textbf{In-Contract Data Abuse (\texttt{S22}):} SQL injection that reads records strictly over the web application's already-permitted database socket violates no process or network contract; Refmon catches such attacks only when response sizes trigger \texttt{response\_anomaly\_repeated} (\texttt{S27}), outbound volume trips CUSUM (\texttt{exfil}), or decoy records trigger \texttt{OVR-CANARY} (\texttt{S08}).
  \item \textbf{Residual Mutation Gaps (\texttt{G1}--\texttt{G5}):} Exactly $10/635$ ($1.6\%$) mutated malicious streams remain uncontained in \texttt{v2.0} on seed \texttt{171139148}: three actors with no external lineage at all connecting to a broadly trusted host class (\texttt{G1}; closing it means a trusted class excuses only roles whose contract lists it, a policy decision with a false-alarm cost), five ultra-slow ransomware mutations modifying 55 files minutes apart (\texttt{G2}--\texttt{G3}), and two slow memory-leak mutations whose oversized responses are minutes apart (\texttt{G4}--\texttt{G5}; one ends $0.02$~nats below $\tau_{\text{hold}}$ because its request label has faded). None is closed by moving a weight or a threshold, which would fit the rule to the seed; the slow cases need a baseline measured in a pilot.
  \item \textbf{User-Space vs.\ Kernel Deployment:} In unprivileged user space on shared HPC nodes, Refmon mediates commands routed through \texttt{refmon guard}, watched staging directories, and user-readable \texttt{/proc}/\texttt{/sys} views. Full non-bypassability against a local attacker who invokes raw syscalls directly requires administrative deployment of kernel-level sensors.
\end{enumerate}

Six directions extend Refmon toward production campus and HPC deployments:

  \item \textbf{Multi-Scale Sub-Threshold CUSUM for Ultra-Slow Ransomware:} Addressing residual gaps \texttt{G2}--\texttt{G3} by tracking cumulative file-entropy shifts and directory-traversal surprisal over multi-day horizons.

\end{enumerate}

\section{Proofs of Provenance Decay and Noisy-OR Fusion}
\label{app:decay}

\begin{proposition}[Monotonicity and Invariance of Label Decay]
\label{prop:decay}
Let $s_\ell(t) = s_0 \cdot 2^{-(t - t_0)/T_{1/2}}$ for $s_0 \in [0, 1]$, $T_{1/2} > 0$, and $t \ge t_0$. Then:
\begin{enumerate}[leftmargin=1.5em,itemsep=1pt,topsep=2pt]
  \item $s_\ell(t) \in [0, s_0] \subseteq [0, 1]$ for all $t \ge t_0$;
  \item $s_\ell(t)$ is strictly decreasing in $t$ whenever $s_0 > 0$, with $s_\ell(t_0 + k T_{1/2}) = 2^{-k} s_0$;
  \item Under edge attenuation $a_e \in (0, 1]$, any $d$-hop causal path $p = (e_1, \dots, e_d)$ satisfies $s_{\text{leaf}}(t) = s_0 \big(\prod_{r=1}^{d} a_{e_r}\big) 2^{-\Delta t / T_{1/2}} \le s_\ell(t)$.
\end{enumerate}
\end{proposition}
\begin{proof}
Since $T_{1/2} > 0$ and $\Delta t = t - t_0 \ge 0$, we have $-\Delta t / T_{1/2} \le 0$, so $0 < 2^{-\Delta t / T_{1/2}} \le 1$, proving $0 \le s_\ell(t) \le s_0 \le 1$. Differentiating with respect to $t$ yields
\[
  \frac{\mathrm{d}s_\ell(t)}{\mathrm{d}t} = -\frac{\ln 2}{T_{1/2}}\, s_0 \, 2^{-(t - t_0)/T_{1/2}} < 0 \quad (\forall s_0 > 0),
\]
establishing strict temporal monotonicity, and direct substitution of $\Delta t = k T_{1/2}$ gives $s_\ell(t_0 + k T_{1/2}) = 2^{-k}s_0$. Finally, because $a_{e_r} \in (0, 1]$ for every edge $e_r$, induction over path length $d$ yields $0 < \prod_{r=1}^{d} a_{e_r} \le 1$, whence $s_{\text{leaf}}(t) \le s_\ell(t)$.
\end{proof}

\begin{theorem}[Algebraic and Dominance Properties of Noisy-OR]
\label{thm:noisyor}
For any finite multiset of label strengths $\mathbf{s} = (s_1, \dots, s_m) \in [0, 1]^m$, define $\operatorname{NOR}(\mathbf{s}) = 1 - \prod_{i=1}^{m}(1 - s_i)$ (with empty product $1$). Then:
\begin{enumerate}[leftmargin=1.5em,itemsep=1pt,topsep=2pt]
  \item \textbf{Range closure:} $\operatorname{NOR}(\mathbf{s}) \in [0, 1]$;
  \item \textbf{Dominance:} $\max_{1 \le i \le m} s_i \le \operatorname{NOR}(\mathbf{s}) \le \min\!\big(1, \sum_{i=1}^{m} s_i\big)$;
  \item \textbf{Commutative monoid:} $\operatorname{NOR}$ is symmetric, associative under binary composition $x \oplus y = 1 - (1-x)(1-y) = x + y - xy$, has identity element $0$, and absorbing element $1$;
  \item \textbf{Coordinate-wise monotonicity:} If $s_i \le s'_i$ for all $i$, then $\operatorname{NOR}(\mathbf{s}) \le \operatorname{NOR}(\mathbf{s}')$.
\end{enumerate}
\end{theorem}
\begin{proof}
(1) Since $s_i \in [0, 1]$, each factor satisfies $1 - s_i \in [0, 1]$, so $P = \prod_{i=1}^{m}(1 - s_i) \in [0, 1]$ and $1 - P \in [0, 1]$.

(2) Fix an arbitrary index $k \in \{1, \dots, m\}$. Because $\prod_{i \neq k}(1 - s_i) \le 1$ and $1 - s_k \ge 0$, we obtain
\begin{align*}
  \prod_{i=1}^{m}(1 - s_i) &= (1 - s_k)\prod_{i \neq k}(1 - s_i) \le 1 - s_k\\
  &\implies \operatorname{NOR}(\mathbf{s}) \ge s_k.
\end{align*}
Taking the maximum over $k$ yields $\operatorname{NOR}(\mathbf{s}) \ge \max_i s_i$. For the upper bound, induction on $m$ using Weierstrass's inequality $\prod_{i=1}^{m}(1 - s_i) \ge 1 - \sum_{i=1}^{m} s_i$ gives $\operatorname{NOR}(\mathbf{s}) \le \sum_{i=1}^{m} s_i$, and combining with (1) gives $\min(1, \sum_i s_i)$.

(3) Symmetry follows from commutativity of real multiplication. For associativity, $(x \oplus y) \oplus z = 1 - (1 - [1 - (1-x)(1-y)])(1-z) = 1 - (1-x)(1-y)(1-z) = x \oplus (y \oplus z)$. Moreover, $x \oplus 0 = 1 - (1-x)\cdot 1 = x$ and $x \oplus 1 = 1 - (1-x)\cdot 0 = 1$.

(4) If $s_i \le s'_i$, then $0 \le 1 - s'_i \le 1 - s_i$ for each $i$, so $\prod_{i=1}^{m}(1 - s'_i) \le \prod_{i=1}^{m}(1 - s_i)$, whence $\operatorname{NOR}(\mathbf{s}) \le \operatorname{NOR}(\mathbf{s}')$.
\end{proof}

\section{Derivation of Bayes-Optimal Thresholds and Contract Gate}
\label{app:bayes}

\begin{theorem}[Bayes Minimal-Risk Log-Odds Thresholds]
\label{thm:bayes_thresholds}
Let $Y \in \{0, 1\}$ denote whether a story $S$ is benign ($Y=0$) or an attack ($Y=1$), and let $p = \mathbb{P}(Y = 1 \mid S) = (1 + e^{-L})^{-1}$ be the posterior attack probability corresponding to log-odds $L = \ln\frac{p}{1-p}$. Suppose:
\begin{itemize}[leftmargin=1.4em,itemsep=1pt,topsep=2pt]
  \item Action $a_{\text{allow}}$ incurs loss $C_{\text{miss}} > 0$ if $Y=1$ and $0$ if $Y=0$;
  \item Action $a_{\text{block}}$ incurs loss $0$ if $Y=1$ and $C_{\text{fb}} > 0$ if $Y=0$;
  \item Action $a_{\text{hold}}$ incurs human-review cost $C_{\text{hold}} > 0$ if $Y=0$, and catches a true attack ($Y=1$) with probability $h \in (0, 1]$ (leaving residual miss cost $(1 - h)C_{\text{miss}}$; when $C_{\text{hold}} \ll C_{\text{miss}}$ we neglect the $O(C_{\text{hold}})$ operational overhead under $Y=1$).
\end{itemize}
Then:
\begin{enumerate}[leftmargin=1.5em,itemsep=1.5pt,topsep=2pt]
  \item Pairwise preference $R(a_{\text{block}} \mid S) \le R(a_{\text{allow}} \mid S)$ holds iff
  \[
    L \ge \tau_{\text{block}} \triangleq \ln\frac{C_{\text{fb}}}{C_{\text{miss}}};
  \]
  \item Pairwise preference $R(a_{\text{hold}} \mid S) \le R(a_{\text{allow}} \mid S)$ holds iff
  \[
    L \ge \tau_{\text{hold}} \triangleq \ln\frac{C_{\text{hold}}}{h \cdot C_{\text{miss}}};
  \]
  \item A non-empty \texttt{HOLD} interval $[\tau_{\text{hold}}, \tau_{\text{block}})$ exists iff $C_{\text{hold}} < h \cdot C_{\text{fb}}$.
\end{enumerate}
\end{theorem}
\begin{proof}
The conditional Bayes risks of the three actions given posterior $p \in (0, 1)$ are:
\begin{align*}
  R(a_{\text{allow}} \mid S) &= p \, C_{\text{miss}},\\
  R(a_{\text{block}} \mid S) &= (1 - p) \, C_{\text{fb}},\\
  R(a_{\text{hold}} \mid S)  &= p (1 - h) C_{\text{miss}} + (1 - p) C_{\text{hold}}.
\end{align*}
For (1), $R(a_{\text{block}} \mid S) \le R(a_{\text{allow}} \mid S)$ iff $(1 - p) C_{\text{fb}} \le p \, C_{\text{miss}}$, which rearranges to
\[
  \frac{p}{1 - p} \ge \frac{C_{\text{fb}}}{C_{\text{miss}}}
  \iff L = \ln\frac{p}{1 - p} \ge \ln\frac{C_{\text{fb}}}{C_{\text{miss}}} = \tau_{\text{block}}.
\]
For (2), $R(a_{\text{hold}} \mid S) \le R(a_{\text{allow}} \mid S)$ iff
\begin{align*}
  p(1 - h)C_{\text{miss}} + (1 - p)C_{\text{hold}} &\le p \, C_{\text{miss}}\\
  \iff (1 - p)C_{\text{hold}} &\le p \, h \, C_{\text{miss}}.
\end{align*}
Dividing by $(1 - p) h C_{\text{miss}} > 0$ and taking natural logarithms yields
\[
  \frac{p}{1 - p} \ge \frac{C_{\text{hold}}}{h \cdot C_{\text{miss}}}
  \iff L \ge \ln\frac{C_{\text{hold}}}{h \cdot C_{\text{miss}}} = \tau_{\text{hold}}.
\]
For (3), by strict monotonicity of $\ln(\cdot)$, $\tau_{\text{hold}} < \tau_{\text{block}} \iff \frac{C_{\text{hold}}}{h C_{\text{miss}}} < \frac{C_{\text{fb}}}{C_{\text{miss}}} \iff C_{\text{hold}} < h \, C_{\text{fb}}$. Substituting Refmon's default policy costs ($C_{\text{hold}} = 5$, $h = 0.7$, $C_{\text{fb}} = 20$) gives $5 < 14$, yielding $\tau_{\text{hold}} = \ln(5/700) = -4.9416 < \tau_{\text{block}} = \ln(20/1000) = -3.9120$.
\end{proof}

\begin{corollary}[Sensitivity Directionality]
$\partial \tau_{\text{block}} / \partial C_{\text{fb}} = 1/C_{\text{fb}} > 0$, $\partial \tau_{\text{block}} / \partial C_{\text{miss}} = -1/C_{\text{miss}} < 0$, and $\partial \tau_{\text{hold}} / \partial h = -1/h < 0$. Thus raising false-block penalties raises the evidence bar for blocking, whereas raising missed-attack cost lowers both thresholds monotonically.
\end{corollary}

\section{Proof of Posterior Monotonicity in \texttt{v1.3} (Resolution of F8)}
\label{app:monotone}

\begin{theorem}[Monotonicity of \texttt{v1.3} Calculus vs.\ Non-Monotonicity of \texttt{v1.2}]
\label{thm:monotone}
Fix a story $S$ with non-empty Contract or Effect signals having positive max weights $W_C = \max_{j \in \mathcal{S}_C} w_j > 0$ and $W_E = \max_{k \in \mathcal{S}_E} w_k \ge 0$, origin weight $w_{\text{ori}} \ge 0$, and origin threshold $\theta \in (0, 1)$.
\begin{enumerate}[leftmargin=1.5em,itemsep=1.5pt,topsep=2pt]
  \item Under the legacy \texttt{v1.2} rule $L_{\text{v1.2}}(s) = L_0 + w_{\text{ori}} s \mathbf{1}[s \ge \theta] + \big(s \mathbf{1}[s \ge \theta] + \mathbf{1}[s < \theta]\big)(W_C + W_E)$, $L_{\text{v1.2}}(s)$ is \textbf{not} non-decreasing on $[0, 1]$ whenever $W_C + W_E > \frac{\theta}{1 - \theta} w_{\text{ori}}$.
  \item Under the \texttt{v1.3} rule $L_{\text{v1.3}}(s) = L_0 + w_{\text{ori}} s \mathbf{1}[s \ge \theta] + W_C + W_E$, $L_{\text{v1.3}}(s)$ is monotonically non-decreasing over all $s \in [0, 1]$ and under arbitrary signal additions with $w_j \ge 0$.
\end{enumerate}
\end{theorem}
\begin{proof}
(1) Evaluate the left and right limits of $L_{\text{v1.2}}(s)$ at $s = \theta$:
\begin{align*}
  \lim_{s \uparrow \theta} L_{\text{v1.2}}(s) &= L_0 + W_C + W_E,\\
  L_{\text{v1.2}}(\theta) &= L_0 + \theta w_{\text{ori}} + \theta(W_C + W_E).
\end{align*}
Hence $L_{\text{v1.2}}(\theta) - \lim_{s \uparrow \theta} L_{\text{v1.2}}(s) = \theta w_{\text{ori}} - (1 - \theta)(W_C + W_E)$. For Refmon's defaults ($\theta = 0.5$, $w_{\text{ori}} = 0.8$), whenever $W_C + W_E > 0.8$ (which holds for \emph{every} Contract + Effect pair in Table~\ref{tab:weights}, e.g., $W_C + W_E = 1.0 + 2.5 = 3.5$), we have $L_{\text{v1.2}}(0.5) - L_{\text{v1.2}}(0.499) = 0.4 - 1.75 = -1.35 < 0$, proving a downward jump where stronger provenance produced weaker evidence.

(2) In \texttt{v1.3}, write $g(s) = w_{\text{ori}} s \mathbf{1}[s \ge \theta]$. For $0 \le s_1 \le s_2 < \theta$, $g(s_1) = g(s_2) = 0$. For $0 \le s_1 < \theta \le s_2 \le 1$, since $w_{\text{ori}} \ge 0$ and $s_2 \ge \theta > 0$, $g(s_1) = 0 \le w_{\text{ori}} s_2 = g(s_2)$. For $\theta \le s_1 \le s_2 \le 1$, $g(s_2) - g(s_1) = w_{\text{ori}}(s_2 - s_1) \ge 0$. Since $W_C$ and $W_E$ are independent of $s$ (apart from D23's indicator $\mathbf{1}[s \ge \theta]$ which only \emph{adds} positive allowed-effect weights when $s$ crosses $\theta$), $L_{\text{v1.3}}(s_1) \le L_{\text{v1.3}}(s_2)$ for all $0 \le s_1 \le s_2 \le 1$. Furthermore, adding any signal $j^*$ with $w_{j^*} \ge 0$ to question set $\mathcal{S}_q$ satisfies $\max_{j \in \mathcal{S}_q \cup \{j^*\}} w_j s_j \ge \max_{j \in \mathcal{S}_q} w_j s_j$, so $L_{\text{v1.3}}$ never decreases when evidence is added.
\end{proof}

\section{Proofs of Laplace Surprisal and Good-Turing Unseen Mass}
\label{app:rarity}

\begin{proposition}[Properness and Surprisal Bounds of Laplace Role Model]
Let $n_1, \dots, n_K \ge 1$ be observed counts summing to $N = \sum_{e=1}^{K} n_e$, and define $\hat{p}(e) = \frac{n_e + \alpha}{N + \alpha(K + 1)}$ for $e \in \{1, \dots, K\}$ and $\hat{p}(\text{unseen}) = \frac{\alpha}{N + \alpha(K + 1)}$ with $\alpha > 0$. Then $\hat{p}$ is a valid probability distribution on $\{1, \dots, K, \text{unseen}\}$, and unseen-event surprisal satisfies $I(\text{unseen}) = \log_2\!\big(\frac{N}{\alpha} + K + 1\big)$.
\end{proposition}
\begin{proof}
Every probability is strictly positive since $n_e \ge 0$ and $\alpha > 0$. Summing over all $K + 1$ outcomes gives
\begin{align*}
  &\sum_{e=1}^{K} \frac{n_e + \alpha}{N + \alpha(K + 1)} + \frac{\alpha}{N + \alpha(K + 1)}\\
  &\quad = \frac{\sum_{e=1}^{K} n_e + K\alpha + \alpha}{N + \alpha(K + 1)} = \frac{N + \alpha(K + 1)}{N + \alpha(K + 1)} = 1.
\end{align*}
Taking $-\log_2 \hat{p}(\text{unseen})$ yields $\log_2((N + \alpha(K+1))/\alpha) = \log_2(N/\alpha + K + 1)$. In particular, for $\alpha = 1$, $I(\text{unseen}) \ge 12$~bits requires $N + K + 1 \ge 2^{12} = 4096$, automatically preventing surprisal false alarms on small samples even before the Good-Turing check.
\end{proof}

\begin{theorem}[Unbiasedness of Good-Turing Unseen Probability Estimator~\cite{good1953population}]
\label{thm:goodturing}
Suppose $N$ i.i.d.\ events are drawn from an unknown discrete distribution $\{p_e\}_{e \in \mathcal{U}}$ over a countable alphabet $\mathcal{U}$. Let $N_e$ be the count of kind $e$ in the first $N$ draws, $U_N = \sum_{e \in \mathcal{U}} p_e \mathbf{1}[N_e = 0]$ be the true random probability mass of kinds unseen in $N$ draws, and $N_1^{(N+1)} = \sum_{e \in \mathcal{U}} \mathbf{1}[N'_e = 1]$ be the number of singletons in a sample of size $N + 1$. Then:
\[
  \mathbb{E}[U_N] = \frac{\mathbb{E}\big[N_1^{(N+1)}\big]}{N + 1} \approx \frac{\mathbb{E}[N_1^{(N)}]}{N}.
\]
\end{theorem}
\begin{proof}
By linearity of expectation and $N_e \sim \operatorname{Binomial}(N, p_e)$,
\[
  \mathbb{E}[U_N] = \sum_{e \in \mathcal{U}} p_e \mathbb{P}(N_e = 0) = \sum_{e \in \mathcal{U}} p_e (1 - p_e)^N.
\]
Conversely, in $N + 1$ i.i.d.\ draws, $\mathbb{P}(N'_e = 1) = (N + 1) p_e (1 - p_e)^N$. Summing over $e \in \mathcal{U}$ and dividing by $N + 1$ gives
\begin{align*}
  \frac{\mathbb{E}\big[N_1^{(N+1)}\big]}{N + 1} &= \frac{1}{N + 1}\sum_{e \in \mathcal{U}} (N + 1) p_e (1 - p_e)^N\\
  &= \sum_{e \in \mathcal{U}} p_e (1 - p_e)^N = \mathbb{E}[U_N].
\end{align*}
For $N \gg 1$, replacing $N+1$ by $N$ yields $\hat{p}_{\text{unseen}} = N_1 / N$ with $O(1/N)$ bias.
\end{proof}

\section{Proofs of Statistical Rate and CUSUM Drift Properties}
\label{app:stats}

\begin{proposition}[Numerical Exactness of Upper-Tail Poisson Recurrence]
For $X \sim \operatorname{Poisson}(\lambda)$ with $\lambda > 0$ and integer $k \ge 1$, the upper tail $T(k, \lambda) = \sum_{i=k}^{\infty} t_i$ with $t_k = \exp(-\lambda + k \ln \lambda - \ln \Gamma(k + 1))$ and recurrence $t_{i+1} = t_i \cdot \frac{\lambda}{i + 1}$ converges strictly monotonically for $i \ge \lceil \lambda \rceil$ with relative truncation error below machine epsilon $\varepsilon_{\text{mach}}$ once $t_i \le \varepsilon_{\text{mach}} \sum_{j=k}^{i} t_j$.
\end{proposition}
\begin{proof}
Computing $\ln t_k$ via $\operatorname{lgamma}(k + 1) = \ln(k!)$ avoids catastrophic cancellation in $1 - \sum_{i=0}^{k-1} t_i$ when $T(k, \lambda) \approx 10^{-12} \ll \varepsilon_{\text{mach}} \approx 2.22 \times 10^{-16}$ (where complement subtraction returns $0.0$). For all $i \ge \max(k, \lceil 2\lambda \rceil)$, $t_{i+1}/t_i = \lambda/(i+1) \le 1/2$, so the omitted tail satisfies $\sum_{j=i+1}^{\infty} t_j \le t_{i+1} \sum_{r=0}^{\infty} 2^{-r} = 2 t_{i+1} \le t_i$, bounding relative error by $\varepsilon_{\text{mach}}$.
\end{proof}

\begin{proposition}[Negative Drift Under Benign Null and Poisoning Immunity]
Let $z_t = (x_t - \mu)/\sigma$ have $\mathbb{E}_0[z_t] = 0$ under benign traffic and $\mathbb{E}_1[z_t] = \delta > k_c > 0$ under slow exfiltration. Then the one-sided CUSUM $S_t = \max(0, S_{t-1} + z_t - k_c)$ has strictly negative pre-reflection increment drift $\mathbb{E}_0[z_t - k_c] = -k_c < 0$ under $\mathcal{H}_0$ (preventing unbounded random-walk drift) and strictly positive drift $\mathbb{E}_1[z_t - k_c] = \delta - k_c > 0$ under $\mathcal{H}_1$, matching the Gaussian log-likelihood ratio test for shift $\delta = 2 k_c$~\cite{page1954continuous,lorden1971procedures}. Moreover, when EMA updates $\hat{\lambda}_t = (1 - \beta)\hat{\lambda}_{t-1} + \beta y_t \cdot \mathbf{1}[\neg\text{incident}]$ are gated on $J.\text{decision} = \texttt{ALLOW}$, any sequence of anomalous bursts during an open incident leaves $\hat{\lambda}_t \equiv \hat{\lambda}_{t_{\text{open}}}$, preventing baseline inflation.
\end{proposition}
\begin{proof}
Under Gaussian $z_t \sim \mathcal{N}(\delta, 1)$ vs.\ $\mathcal{N}(0, 1)$, the single-step log-likelihood ratio is $\ln \frac{\phi(z_t - \delta)}{\phi(z_t)} = \delta z_t - \frac{\delta^2}{2} = \delta\big(z_t - \frac{\delta}{2}\big)$. Setting $k_c = \delta/2 > 0$ scales Page's SPRT recursion directly into Eq.~\eqref{eq:cusum}. Under $\mathcal{H}_0$, $\mathbb{E}_0[z_t - k_c] = -k_c < 0$; under $\mathcal{H}_1$ with $\delta > k_c$, $\mathbb{E}_1[z_t - k_c] = \delta - k_c > 0$. Finally, during $[t_{\text{open}}, t_{\text{close}}]$, $\mathbf{1}[\neg\text{incident}] = 0 \implies \hat{\lambda}_t = \hat{\lambda}_{t_{\text{open}}}$ by trivial induction.
\end{proof}

\section{Proofs of Differential Privacy and Zero-FP Bloom Filtering}
\label{app:privacy}

\begin{theorem}[$\varepsilon$-Differential Privacy of Aggregate Fleet Counts]
Let $D, D'$ be neighboring device-telemetry datasets differing in the state of at most one device, and let $f(D) \in \mathbb{N}$ count the number of devices experiencing a given rule or tactic ($\Delta f = \max_{D \sim D'} |f(D) - f(D')| = 1$). Then the mechanism $\mathcal{M}(D) = f(D) + \eta$ where $\eta$ is sampled via inverse transform $F^{-1}(u) = -\frac{1}{\varepsilon}\operatorname{sgn}(u - \tfrac{1}{2})\ln\big(1 - 2|u - \tfrac{1}{2}|\big)$ for $u \sim \operatorname{Uniform}(0, 1)$ satisfies pure $\varepsilon$-differential privacy.
\end{theorem}
\begin{proof}
First, for $y \ge 0$, $\mathbb{P}(F^{-1}(u) \ge y) = \mathbb{P}\big(u - \tfrac{1}{2} \ge \tfrac{1}{2}(1 - e^{-\varepsilon y})\big) = \frac{1}{2}e^{-\varepsilon y}$; by symmetry around $0$, $\eta$ has density $p_\eta(z) = \frac{\varepsilon}{2}\exp(-\varepsilon |z|)$, i.e., $\eta \sim \operatorname{Lap}(0, 1/\varepsilon)$. Second, for any measurable output $z \in \mathbb{R}$ and neighboring $D, D'$ with $|f(D) - f(D')| \le \Delta f = 1$, the reverse triangle inequality $|z - f(D')| - |z - f(D)| \le |f(D) - f(D')| \le 1$ gives:
\begin{align*}
  \frac{p_{\mathcal{M}(D)}(z)}{p_{\mathcal{M}(D')}(z)}
  &= \frac{\frac{\varepsilon}{2}\exp(-\varepsilon |z - f(D)|)}{\frac{\varepsilon}{2}\exp(-\varepsilon |z - f(D')|)}\\
  &= \exp\!\Big(\varepsilon\big(|z - f(D')| - |z - f(D)|\big)\Big) \le e^{\varepsilon}. \qedhere
\end{align*}
\end{proof}

\begin{theorem}[Optimal Sizing and Zero Operational False Positives of Confirmed Bloom Threat Lists]
\label{thm:bloom}
For $n$ threat entries inserted into an $m$-bit array using $k_h$ independent hash positions, the asymptotic filter false-positive probability $p(k_h) = \big(1 - e^{-k_h n / m}\big)^{k_h}$ is minimized at $k_h^* = \frac{m}{n}\ln 2$, requiring $m = \lceil -n \ln p_{\text{fp}} / (\ln 2)^2 \rceil$ bits for target hint rate $p_{\text{fp}}$. Moreover, two-stage confirmation $H(x) = \mathbf{1}[\mathcal{B}(x) = 1 \land d(x) \in \mathcal{D}_{\text{exact}}]$ achieves zero false negatives relative to $\mathcal{D}_{\text{exact}}$ and false-positive probability $\le 2^{-256}$ (HMAC-SHA256 collision bound).
\end{theorem}
\begin{proof}
Let $g(k_h) = \ln p(k_h) = k_h \ln(1 - e^{-k_h n / m})$. Setting $x = e^{-k_h n / m} \in (0, 1)$ gives $k_h = -\frac{m}{n}\ln x$ and $g = -\frac{m}{n}\ln x \ln(1 - x)$. Differentiating with respect to $x$:
\begin{align*}
  \frac{\mathrm{d}g}{\mathrm{d}x} &= -\frac{m}{n}\!\left(\frac{\ln(1 - x)}{x} - \frac{\ln x}{1 - x}\right) = 0\\
  &\iff x = 1 - x \iff x = \frac{1}{2}.
\end{align*}
Substituting $x = 1/2$ yields $k_h^* = \frac{m}{n}\ln 2$ and $p(k_h^*) = (1/2)^{(m/n)\ln 2} = e^{-m(\ln 2)^2 / n} \le p_{\text{fp}} \iff m \ge -n \ln p_{\text{fp}} / (\ln 2)^2$. Finally, because a Bloom filter has zero false negatives ($d(x) \in \mathcal{D}_{\text{exact}} \implies \mathcal{B}(x) = 1$), $H(x) = 1 \iff d(x) \in \mathcal{D}_{\text{exact}}$; for $x \notin \mathcal{D}_{\text{bad}}$, $d(x) \in \mathcal{D}_{\text{exact}}$ occurs only on an HMAC-SHA256 collision across $n$ entries ($\le n \cdot 2^{-256}$ under PRF security~\cite{bellare1996keying}).
\end{proof}

\section{Bounds of the Trust Mark (\texttt{v2.0}, A65)}
\label{app:trust}

\begin{proposition}[Trust Never Outlives or Outreaches a Label]
\label{prop:trust}
Let process $p$ ingest trusted-root content at $t_p$, let $s_{\text{floor}} \in (0, 1)$ be the label alive floor, and let $\operatorname{trust}_p(t)$ be defined by Eq.~\eqref{eq:trust}. Then:
\begin{enumerate}[leftmargin=1.5em,itemsep=1pt,topsep=2pt]
  \item \textbf{Lifetime:} $\operatorname{trust}_p(t) = 1$ implies $t - t_p \le T_{1/2}\log_2(1/s_{\text{floor}})$, the lifetime of a non-persistent label without contract evidence created at $t_p$;
  \item \textbf{Cancellation:} if any label in $\operatorname{ever}(p)$ is alive at $t$, then $\operatorname{trust}_p(t) = 0$, whatever its strength relative to $\theta_{\text{ori}}$;
  \item \textbf{Reach:} the mark reaches only $p$ and the processes spawned in its lineage; a channel role that ingests trusted content does not acquire it, and no file or persistence item carries it, so a startup entry written under trust starts a later story without trust;
  \item \textbf{Precedence:} no story containing a self-tamper, canary or protected-asset flag is allowed by the mark.
\end{enumerate}
\end{proposition}
\begin{proof}
(1) The first factor of Eq.~\eqref{eq:trust} is $1$ iff $2^{-(t - t_p)/T_{1/2}} \ge s_{\text{floor}} \iff t - t_p \le T_{1/2}\log_2(1/s_{\text{floor}})$, which by Eq.~\eqref{eq:decay} with $s_0 = 1$ is exactly the time at which such a label falls below the floor (Proposition~\ref{prop:decay}). With $T_{1/2} = 30$~min and $s_{\text{floor}} = 0.02$ this is $30 \log_2 50 \approx 169$~min. (2) The second factor is $0$ by definition. (3) The mark is set on an ingesting process only when its role is not a channel role, and copied only when a new process is created with $p$ (or a descendant) as parent; rule~5 (files and persistence items) copies labels, never the mark. (4) \texttt{Judge} evaluates the overrides in the fixed order self-tamper $\succ$ canary $\succ$ protected asset $\succ$ trusted root and returns the first that applies, so the trusted-root override is reached only when none of the blocking overrides is present.
\end{proof}

\section{Proof of Multi-Pass Rootkit Churn Suppression}
\label{app:rootkit}

\begin{proposition}[Exponential Suppression of Transient OS Race Discrepancies]
\label{prop:rootkit_churn}
Suppose during pass $r \in \{1, \dots, m\}$ separated by $\Delta\tau$ exceeding typical syscall directory-walk latency, a benign short-lived entity $x$ (such as an exiting worker PID or unloading kernel module) produces a transient cross-view race $x \in \mathcal{V}_{\text{low}}^{(r)} \setminus \mathcal{V}_{\text{high}}^{(r)}$ with probability $p_{\text{race}} \ll 1$ on Pass~1 and conditional persistence probability $q_{\text{persist}} \ll 1$ on each subsequent pass, whereas a stealth rootkit actively hiding $x^*$ satisfies $x^* \in \mathcal{V}_{\text{low}}^{(r)} \setminus \mathcal{V}_{\text{high}}^{(r)}$ with probability $p_{\text{tp}} \approx 1$ on every pass. Then for $\Delta_{\text{pers}} = \bigcap_{r=1}^{m}(\mathcal{V}_{\text{low}}^{(r)} \setminus \mathcal{V}_{\text{high}}^{(r)})$:
\begin{align*}
  \mathbb{P}(x \in \Delta_{\text{pers}} \mid \text{benign}) &= p_{\text{race}} \cdot q_{\text{persist}}^{\,m - 1},\\
  \ln\frac{\mathbb{P}(x \in \Delta_{\text{pers}} \mid \text{rootkit})}{\mathbb{P}(x \in \Delta_{\text{pers}} \mid \text{benign})}
  &= \ln\frac{p_{\text{tp}}}{p_{\text{race}}} + (m - 1)\ln\frac{1}{q_{\text{persist}}}.
\end{align*}
\end{proposition}
\begin{proof}
By the chain rule of conditional probability under $\mathcal{H}_0$ (benign OS churn) across passes $1, \dots, m$,
\begin{align*}
  \mathbb{P}\!\left(\bigcap_{r=1}^{m} E_r \;\middle|\; \mathcal{H}_0\right)
  &= \mathbb{P}(E_1 \mid \mathcal{H}_0) \prod_{r=2}^{m} \mathbb{P}(E_r \mid E_{1..r-1}, \mathcal{H}_0)\\
  &= p_{\text{race}} \, q_{\text{persist}}^{\,m - 1}.
\end{align*}
Under a persistent rootkit hook (e.g., an LKM unlinked from \texttt{modules} list but still mounted in \texttt{/sys/module}, or \texttt{getdents64} filtering PID $x^*$), $E_r$ holds deterministically across passes ($\mathbb{P}(\bigcap_{r=1}^{m} E_r \mid \text{rootkit}) = p_{\text{tp}}$). Taking the natural log-likelihood ratio yields $\ln(p_{\text{tp}} / p_{\text{race}}) + (m - 1)\ln(1 / q_{\text{persist}})$, and applying the policy cap $w_{\max}$ yields Eq.~\eqref{eq:rk_nats}. For $p_{\text{race}} = 0.02$, $q_{\text{persist}} = 0.05$, and $m = 2$, benign race probability drops from $2 \times 10^{-2}$ to $10^{-3}$ ($20\times$ reduction) in a single $50$~ms interval.
\end{proof}
